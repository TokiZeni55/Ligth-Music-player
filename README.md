# Ligth Music Player Installation Guide

## Quick Start

If the standalone `Ligth Music Player.exe` works on your computer, you can simply download it and open it.

No installation is required.

## If the EXE Does Not Work

If the standalone EXE does not start correctly, download the ZIP file from the Releases section instead.

1. Download `Ligth Music Player.zip`.
2. Right click the ZIP file.
3. Select Extract All.
4. Choose where you want to extract the files.
5. Open the extracted folder.
6. Run `Ligth Music Player.exe`.

Make sure you extract the entire ZIP before starting the program. Do not move the EXE out of the extracted folder if the program requires files included with it.

## Windows Security Warning

Windows may show a security warning when running an application downloaded from the internet. Only continue if you downloaded Ligth Music Player from the official GitHub repository or its GitHub Releases page.

## Still Not Working

If Ligth Music Player still does not start, please open an issue on the GitHub repository and include your Windows version and any error message shown by the program.
